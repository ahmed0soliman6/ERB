# ERB — نظام إدارة مخازن المجمع الطبي

هذا المستودع يحتوي على نواة تطبيق Desktop محلي وفق التصميم المعتمد لنظام إدارة المخازن.

## القرار التقني

- C# وWindows Forms.
- .NET Framework 4.8.
- هدف البناء `x86` لدعم Windows 7 SP1 32-bit و64-bit.
- SQLite محلية داخل ملف بيانات واحد.
- لا توجد Firebase أو Supabase أو Cloud Database أو API أو Internet dependency.
- قاعدة الحقيقة الكمية هي `stock_movements`.

## الموجود في هذه النسخة

- Solution ومشروع WinForms قابل للبناء على Windows مع Visual Studio.
- إنشاء قاعدة SQLite محلية تلقائيًا عند أول تشغيل.
- مخطط أولي كامل للجداول الرئيسية والحركات والمستندات والجرد والصلاحيات والتدقيق والترخيص والنسخ الاحتياطي.
- خدمة حركات تمنع الرصيد السالب وتنفذ التحويل عبر معاملة ذرية.
- واجهة Dashboard أولية تعرض الأرصدة الناتجة من الحركات.
- مخازن افتراضية: الرئيسي، الطوارئ، أدوية العمليات، ومستلزمات العمليات.
- وحدات قياس أولية منفصلة عن الملاحظات.

## البناء على Windows

1. ثبت Visual Studio مع Desktop development for .NET Framework.
2. افتح `ERB.sln`.
3. استعد حزمة `System.Data.SQLite.Core` من NuGet أثناء التطوير فقط.
4. اختر `Release | x86`.
5. نفذ Build.
6. انسخ مجلد `Database` بجانب ملف التشغيل في حزمة التوزيع.

التطبيق النهائي لا يحتاج إلى Node.js أو Python. أما استعادة حزمة NuGet فهي خطوة بناء للمطور وليست اعتماد تشغيل للمستخدم النهائي.

## البيانات

يضع التطبيق قاعدة البيانات في:

```text
%LOCALAPPDATA%\ERB\inventory.db
```

ولا يضعها داخل `Program Files` حتى لا يحتاج المستخدم إلى صلاحيات Administrator أثناء التشغيل.

## الحالة الحالية

هذه نسخة تأسيسية قابلة للبناء وليست إصدارًا إنتاجيًا كاملًا بعد. الواجهات التشغيلية التفصيلية، Login/RBAC الكامل، Import/Mapping، التصدير، Backup/Restore، License Activation، واختبارات Windows الفعلية هي مراحل تالية يجب تنفيذها قبل التسليم الإنتاجي.

لا يتم اعتبار المشروع مكتملًا تجاريًا قبل اعتماد اختبارات Windows 7 SP1 32-bit و64-bit وWindows 8.1 وWindows 10 وWindows 11.
