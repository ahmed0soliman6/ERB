# 🏥 SoliMedical-ERB | نظام إدارة مستودعات المجمع الطبي (إصدار سطح المكتب ويندوز)

نظام متكامل وخفيف الوزن لإدارة وتتبع حركة المستودعات الطبية، الجرد، مراقبة تواريخ الصلاحية، وحد إعادة الطلب (Reorder Point)، مصمم للعمل محلياً بالكامل **Offline** على أنظمة تشغيل **Windows 8.1 / 10 / 11**.

---

## ✨ المميزات الرئيسية:
- 🏢 **إدارة المخازن المتعددة:** المخزن الرئيسي، مستهلكات العمليات، أدوية العمليات، ومستلزمات الطوارئ.
- 📦 **دليل الأصناف والكتالوج الطبي الموحد:** بضاعة أول المدة، الوارد (+)، المنصرف (-)، والرصيد المتبقي.
- 📄 **إدارة المستندات المخزنية:** توريد بضاعة، تحويل بين المخازن، صرف للأقسام، واستهلاك سريري.
- 📊 **لوحة تحكم تفاعلية مع Recharts:** رسوم بيانية لحركة التدفقات المخزنية وتوزيع الأصناف.
- ⚠️ **تقرير نواقص وحد الطلب (Reorder Point):** كشف فوري للنواقص واحتساب كميات العجز المطلوبة وتصدير Excel.
- 🔒 **أمان وصلاحيات متعددة:** أدوار مستخدمين (Admin, Store Manager, Store User, Viewer) مع تشفير كلمات المرور.
- 🛡️ **نظام ترخيص أوف لاين آمن:** يعمل محلياً بدون إنترنت مع حماية التلاعب بالساعة وتاريخ النظام.

---

## 🚀 تشغيل وبناء التطبيق محلياً:

### 1. تثبيت الاعتماديات:
```bash
npm install
```

### 2. التشغيل في بيئة التطوير (Web Dev Mode):
```bash
npm run dev
```

### 3. بناء ملف التثبيت المباشر للويندوز (`.exe`):
```bash
npm run electron:build
```
> بعد انتهاء الأمر، ستجد الملفات التالية جاهزة داخل مجلد `release/`:
> - 📦 **`SoliMedical-ERB-Setup-1.0.0-x64.exe`**: برنامج التثبيت والتنصيب الرسمي (مع أيقونة سطح المكتب وقائمة Start).
> - 🚀 **`SoliMedical-ERB-Portable-1.0.0.exe`**: نسخة محمولة تعمل فوراً بنقرة واحدة بدون تنصيب.

## 🤖 البناء التلقائي عبر GitHub Actions:

2. ستتمكن من تنزيل ملف الـ `.exe` مباشرة من تبويب **Actions** أو **Releases** على GitHub.
